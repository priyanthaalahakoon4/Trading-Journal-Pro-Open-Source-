# 🧾 Trade Journal

A simple PHP + MySQL trade journaling tool to log and track your trading performance. Built for manual traders who want control and clarity without bloated features.

## 🚀 Features

- Log every trade manually
- Dashboard view with PnL, status, date, and pair
- Detailed trade view with:
  - Entry, SL, TP, PnL
  - Trade image
  - Market conditions (Normal, Strong Bullish, Strong Bearish, or custom)
  - Notes
  - Status (Open, Limit, Closed)
  - Pair selection (BTCUSDT or custom)
  - Date of trade

## 🛠️ Tech Stack

- PHP (Backend)
- MySQL (Database)
- HTML/CSS + minimal JS (Frontend)
- Works locally or can be hosted


## 📸 Trade Details Page

Each trade shows:

- **Entry**, **Stop Loss**, **Take Profit**
- **Trade Image** (screenshot/markup of the setup)
- **PnL** (color-coded: green for wins, red for losses)
- **Market Conditions** (dropdown or custom)
- **Notes**
- **Pair**
- **Status**
- **Date**

## 🧠 Why Use This?

- No cloud-based traps or signal-selling BS
- Designed for real traders who want to understand their edge
- Helps build discipline through manual logging

## ✅ How to Use

1. Download the Source code ZIP file
2. Upload and extract to the hosting
3. Move the extracted files to main directory or any sub folder you want
4. Create a mysql databse and keep the creadentials.
5. Visit your website url (It will automatically redirect you to the installation wizard )
6. Follow the Installating wizard.
